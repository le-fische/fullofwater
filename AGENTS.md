# Agent instructions for this workspace

## Living idea doc

`idea.md` is the project's living design doc. Whenever the user shares a new idea, changes an existing one, or makes a decision:

1. Update `idea.md`: put the idea in the right section (or a new section), keeping the user's wording where possible.
2. Add a dated line to the Changelog at the bottom of `idea.md` and bump "Last updated".
3. Agent suggestions go in the Idea Parking Lot, clearly marked as not accepted, until the user accepts them.
4. When the user answers an open question from `spec.md`, record it in the Decision Log in `idea.md` and update `spec.md` to match.
5. If a new idea raises feasibility concerns, add them to `spec.md` and mention them to the user.
